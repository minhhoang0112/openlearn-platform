# Tài liệu tham khảo lịch sử

Thư mục này phục vụ nghiên cứu và đối chiếu, không được import khi chạy OpenLearn.
Các trình thu thập cần trình duyệt riêng do bạn mở qua `inspect-browser.bat`; không cần chạy chúng để cài web.

Bundle / HTML tải từ trang tham khảo và ba script phân tích bundle một lần đã được bỏ khỏi repo. Kết quả phân tích vẫn còn trong các báo cáo JSON / Markdown. Các mục nhắc tới `research/index.js` trong báo cáo cũ là bằng chứng lịch sử, không phải phụ thuộc hiện tại.
